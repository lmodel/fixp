# References

* [FIX Performance Session Layer](fixp-specification.md) - The FIX Trading Community's repository for FIXP, `FIXTradingCommunity/fixp-specification`, which holds each edition's chapters and resource files under CC BY-ND 4.0. The project pins 1.0 at the tag `v1.0-STANDARD`.
* [lmodel/fix-sbe](lmodel-fix-sbe.md) - The sibling LinkML model of FIX Simple Binary Encoding, whose `SbeMessageV1` defines a message template and whose value lists name the SBE primitive types, byte orders and FIX datatypes this schema's annotations use.
* [lmodel/fix-orchestra](lmodel-fix-orchestra.md) - The sibling LinkML model of FIX Orchestra, whose `OrchestraMessageV10` defines a message in an Orchestra file such as FIXP's.
