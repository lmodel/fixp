# AI covenant

A model is a tool, and the person who submits a change answers for it.[^ai_covenant]

This repository models someone else's standard. So the covenant adds rules of its own: every element rests on a named part of the specification, no rule goes beyond what the specification states, and every description is this project's own.[^ai_covenant]
