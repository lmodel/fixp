# Policies

* [AI covenant](ai-covenant.md) - The rules for AI-assisted work here: a person owns every contribution, an element says what FIXP's files say, a rule states only what the specification states, a mapping names a sure match or is absent, and FIX's words stay FIX's.
* [Licence and attribution](license-and-attribution.md) - Whose work each part is: the code and the schema under Apache-2.0, the bundle under CC BY 4.0, and FIXP's three resource files whole and unchanged under CC BY-ND 4.0.
* [Security policy](security-policy.md) - How to report a vulnerability, what this repository releases, what executes here and what holds each surface. A report goes through GitHub's private vulnerability reporting, and only the latest release receives fixes.
