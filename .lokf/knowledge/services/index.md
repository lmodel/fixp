# Services

* [Documentation site](documentation-site.md) - The knowledge website in `website/`, an Astro Starlight site that the Knowledge website workflow publishes to GitHub Pages at `https://lmodel.github.io/fixp`, built from the README, `docs/`, the schema's pages and this bundle.
* [The upstream check](upstream-check.md) - `scripts/check_upstream_release.py`: lists FIX's FIXP repository through GitHub's API and reports a new tag or edition folder, a moved tag, a changed or missing pinned file, or a changed licence.
